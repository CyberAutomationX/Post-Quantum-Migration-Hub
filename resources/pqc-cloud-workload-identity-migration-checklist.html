Recommended use

  1. Use the Checklist sheet to assign owners, priorities, due dates, and evidence links.
  2. Populate the Workload_Identity_Inventory for P1 applications and shared platforms.
  3. Populate the Certificate_and_Key_Map for TLS, mTLS, token signing, KMS/HSM, and CA dependencies.
  4. Review the source-status register and supplier evidence before approving protocol profiles or provider commitments.
  5. Run Pilot_Test_Plan in non-production before production change approval.
